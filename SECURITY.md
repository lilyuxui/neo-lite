# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of Neo-Lite.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier versions | No |

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue or discussion.

Use GitHub's private vulnerability reporting flow:

https://github.com/lilyuxui/neo-lite/security/advisories/new

Include the affected component or package version, reproduction steps, impact,
and any suggested mitigation. You should receive an acknowledgement within
seven days. Please allow time for a fix and coordinated release before sharing
the issue publicly.

## Scope

Reports about the React components, npm package, build configuration, and
deployed documentation or Storybook site are in scope. Reports that require an
intentionally exposed local development server are still useful, but should
clearly describe that prerequisite.
